## 🌟 Overview
An Awwwards-inspired digital agency portfolio clone recreating the fluid, high-end design experience of **Lazarev Digital Product Agency**. Built to demonstrate cutting-edge creative frontend development, modern typography hierarchy, and micro-interactions.

---

## 🚀 Key Features

- 🏎️ **Smooth Inertia Scrolling**: Natural momentum scrolling mechanics delivering an app-like desktop experience.
- 🎥 **Interactive Case Studies**: Hover-activated video thumbnails and expanding project preview cards.
- 🔠 **Kinetic Typography & Badges**: Bold headline animations, floating UI chips, and dynamic layout reflows.
- 🎨 **Minimalist Luxury Aesthetic**: High-contrast dark theme, crisp typography, and refined whitespace balance.
